# Облако и страницы регистрации по QR

- `loyalty_signups.sql` — таблицы и функции облака (выполняется в Supabase → SQL Editor целиком).
- `registration-page/` — страницы для репозитория `Struktura-crm/struktura-booking` (GitHub Pages):
  `register.html`, `consent.html`, `privacy.html`, `loyalty-config.js` (единственный файл настроек и реквизитов).
  `qr-register.png` — QR-код на `…/struktura-booking/register.html?slug=struktura` для печати.
- Обмен приложения с облаком — `db/supabase.js` и `db/loyaltySync.js`; на странице — блок `BEGIN API … END API`
  в `register.html`. При переезде на свой сервер меняются только они.


## Страницы для клиентов: регистрация по QR и онлайн-запись (новое)

Оформление, тексты, меню, схема «Как нас найти» и бонус настраиваются **в приложении**:
- регистрация по QR — «Клиенты» → «⋯» (рядом с «Фильтры») → «Страница регистрации по QR»;
- онлайн-запись — «Записи» → «⋯» → «Страница записи» (и «Подключение, ссылка и QR»).

В обоих окнах справа живой предпросмотр, кнопка «Опубликовать» отправляет настройки в облако.

### Что выложить (один раз)
1. **Облако:** Supabase → SQL Editor → вставить весь `cloud/client_pages.sql` → Run (после `loyalty_signups.sql`; безопасно запускать повторно).
2. **Страницы:** в репозиторий страниц (`Struktura-crm/struktura-booking`, корень) загрузить:
   - `cloud/pages/register.html` → как `register.html`
   - `cloud/pages/index.html` → как `index.html`
   - `consent.html`, `privacy.html`, `loyalty-config.js` — остаются прежними (заполните реквизиты оператора в `loyalty-config.js`).
3. **В приложении:** «Записи» → «⋯» → «Подключение, ссылка и QR» → «Подключить» (если ещё не подключено), затем «Опубликовать» в нужной странице.

### Как это устроено
- Страницы читают настройки функциями `get_client_page` / `get_booking_page`; занятое время — `get_busy` (только начало и конец, без имён и телефонов).
- Запись создаёт `create_booking_public`; сама база не даёт записаться на занятое время (триггер `bookings_overlap_guard`): учитываются длительность услуги, записи по телефону, рабочие часы и число мастеров (одновременных записей).
- Приложение присылает занятое время записей по телефону автоматически при каждом изменении (`sync_busy_slots_secure`); без интернета отправка повторится при следующем открытии.
- Проверка облачной логики: `cloud/tests/client_pages.test.sql`.

### Сборка страниц
Шаблоны — `cloud/pages/src/*.tpl.html`. После правки: `node cloud/pages/build.js` (подставляет шрифты и логотип, обновляет `register.html`, `index.html` и `assets/pages/pages.js` для предпросмотра в приложении).
